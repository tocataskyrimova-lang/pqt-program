## E2. H2 — переформулировка по реальному исходнику

**Источник:**
`C:\AGI\PQT-transformers\pqt_qg_benchmark\pqt_qg\nonlocal_memory.py`
SHA-256 `5c644b102afa3ad7eea3dbe96cfd11b46fbbde81dafd1bda489d6e0da3a98763`, 167 строк,
функция `neutral_mass_entries(phi, r, s, params)`.
Скрипт вывода: `h2b_real_hessian.py` (sympy), результат: `h2b_results.json`.

**Что исходник реально содержит.** Все три портала — квартические:

```
a_rho  * phi^2 * rho^2 / 2
a_iota * phi^2 * iota^2 / 2
c      * rho^2 * iota^2 / 2
```

Трёхлинейного `λ·h·I·σ` **нет**. Каждый недиагональный элемент имеет вид
(связь)·(vev1)·(vev2):

```
x = m_φρ   = a_rho  * phi * rho
p = m_φι   = a_iota * iota * phi
y = m_ρι   = c      * iota * rho
```

**Моя ошибка.** В rev 2 я постулировал cubic `λ·h·I·σ`, из которого следует
`p = λ·s`, и на этом основании заявил, что `s = ⟨I⟩ ≠ 0` **взаимно исключает**
опубликованный `D_eff`. Это утверждение держалось ровно на моём искусственном
анзаце, а не на исходнике. **Илори права**: её контрпример (квартика `a·h²I²`
плюс билинейный `I·σ` без `h–σ` связи) логически корректен и даёт `p = 0`
при `⟨I⟩ ≠ 0`. Формулировку снимаю.

**Что остаётся верным.** Точный Schur-комплемент после интегрирования ι:

```
D_exact = [[ A − p²/C ,  x − p·y/C ],
           [ x − p·y/C ,  B − y²/C ]]

D_pub   = [[ A         ,  x         ],
           [ x         ,  B − y²/C ]]

Δ = D_exact − D_pub:
  Δ[0,0] = −2·a_iota²·iota²·phi² / C
  Δ[0,1] = −2·a_iota·c·iota²·phi·rho / C
  Δ[1,1] = 0
```

Здесь `C = −2Σ + a_iota·phi² + 6·b_iota·iota² + c·rho² + 2·m_iota²`
(в согласии с `h2b_results.json`, поле `schur_exact`).

Важное уточнение: это **не** «частный случай p = 0». При `p = 0` (то есть
`a_iota·phi·iota = 0`) оба Δ тоже равны нулю — но `p = 0` здесь означает
`a_iota = 0`, то есть **выключен сам портал h–ι**, а ι при этом перестаёт
смешиваться с Хиггсом на древесном уровне. То есть published форма точна
ровно в том пределе, где её предмет (h–ι смешивание) исчезает.

**Численная величина** (benchmark из `h2b_results.json`, `C_iota = 2.68927`,
`p/C = 0.03631`):

```
собственные значения, точные:     1.0911618125 , 1.8136948631
собственные значения, published:  1.0944990625 , 1.8139033792
относительная ошибка:             3.058e-03    , 1.150e-04
```

Скан по `a_iota` (максимальная относительная ошибка собственных значений):

| a_iota | 0.00 | 0.05 | 0.10 | 0.20 | 0.35 | 0.50 | 0.80 |
|---|---:|---:|---:|---:|---:|---:|---:|
| max rel err | 2.4e-16 | 4.41e-05 | 2.24e-04 | 9.80e-04 | 3.06e-03 | 6.21e-03 | 1.55e-02 |

**Итоговая формулировка (принята):** `published D_eff` — это **CONDITIONAL
MODEL MISMATCH**, а именно незаявленное приближение, опускающее члены
`O(p²/C, p·y/C)`; симметрией не защищено; ошибка растёт как `a_iota²`;
в пределе `a_iota → 0` точна.

## E3. Тахион ≠ призрак — подтверждено кодом

В rev 2 я написал: «неверный знак ядра даёт полюса `k0² = k² − m²` = призрак»
и фактически использовал `det < 0` как критерий. Это неполный тест.
**Подтверждаю из исходника**, что в этой модели кинетика действительно
неканоническая, и правильный тест — другой.

`nonlocal_memory.py`:

```python
def iota_inverse(q_values, m_iota_local2, kernel_name, kp):
    return kp.Z_iota * q + float(m_iota_local2) - sigma_E(q, kernel_name, kp)
```

Это обратный пропагатор ι в евклидовой переменной `q`. Физический полюс —
корень `iota_inverse(q) = 0` при `q → −k²`, а **не** условие `m² > 0` на
элементе массовой матрицы. Соответственно:

* **тахион** — отрицательный корень обобщённой задачи собственных значений
  `det(M² − λ K) = 0` (при неединичной `K`); при `K = Z(q)` это
  `det(M² − λ·Z) = 0`, а не `det M² < 0`;
* **призрак** — знак вычета, то есть знак
  `d(iota_inverse)/dq = Z_iota − Σ_E′(q)`. При `Z_iota − Σ_E′(q) < 0`
  получаем неправильный знак кинетического члена **даже при положительной
  mass²**. Обратное тоже верно: отрицательная mass² без анализа `K` не
  доказывает призрака.

Сам исходник это и проверяет — в `V1_neutral_nonlocal` три **раздельных**
условия, а не одно:

```python
"nonlocal_det_healthy": bool(np.all(det > 0) and np.all(inv_iota > 0) and min_eval > 0),
"nonlocal_det_negative": bool(np.any(det < 0)),
"nonlocal_det_near_zero": bool(np.any(np.abs(det) < 1e-10)),
"nonlocal_iota_inverse_negative": bool(np.any(inv_iota < 0)),
```

**Итог:** мой rev-2 тест является необходимым, но не достаточным. Полный тест
должен включать (а) обобщённую задачу `(M², K)`, (б) знак
`Z_iota − Σ_E′(q)` по всей сетке квадратур, (в) отсутствие нулей
`iota_inverse` в физической области. Ничего из этого в замороженном H2 не
выполнялось; призраков я **не проверял**, и утверждение о призраке отзывается
как непроверенное.

## E5. |δσ| < 2.9e-4 GeV² — ОТОЗВАНО

Корнелловская подгонка фитирует `σ = 0.16883` GeV² по тем же расщеплениям,
которые используются для ограничения. Сдвиг `δσ·r` при refit переопределяет
`σ → σ + δσ` и **полностью поглощается**: расщепления восстанавливаются,
ограничение исчезает.

Следовательно `|δσ| < 2.9e-4` GeV² — это не физическая граница, а артефакт
того, что я зафиксировал `σ`. Для получения содержательного ограничения нужен
коррелированный refit с `δσ` как свободным параметром и профилированием.
Такой подгонки в замороженном H3 нет. Значение помечаю как **RETRACTED**.

Абсолютные сдвиги (таблица ниже) остаются корректными как **чувствительность**
при зафиксированной `σ`, но не как bound:
