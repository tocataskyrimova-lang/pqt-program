То есть «12-значное согласие» не является свидетельством точности — оно лишь
подтверждает, что использованы одинаковые входы.

### 1.3 K4□K4 против 64 кодонов

Спектр посчитан как кронекеровы суммы спектров K4 (собственные значения смежности
3, −1, −1, −1; лапласиана 0, 4, 4, 4):

* вершин **16**, рёбер **48**
* спектр смежности: `6 (×1), 2 (×6), −2 (×9)`
* спектр лапласиана: `0 (×1), 4 (×6), 8 (×9)`
* |Σ³| кодонов = **64** = 16 × 4

Отношение 16→64 требует **дополнительного фактора 4** (4 кодоновых слота на вершину
либо 4-элементное расслоение). Сам по себе граф 64 элемента не даёт — путать их нельзя,
и структурно это расхождение снимается только явным заданием отображения.

Попытка вывести κ=8.78, η=0.351, γ=0.251, β=2.96 из спектра: **точного совпадения нет**.
Ближайшие совпадения (γ=0.251 против 1/4, β=2.96 против 3, κ=8.78 против старшего
лапласиановского 8) расходятся на 0.4%, 1.3% и 10% — это **не доказательство**.
Без исходника происхождение коэффициентов установить нельзя.

## 2. H2 — скалярный сектор (структурный аудит, SymPy)

Обозначения (базис h, I, σ): `M2 = [[A,x,p],[x,B,y],[p,y,C]]`, где **p — прямой член h–σ**.

### 2.A Schur complement

Точный результат после интегрирования тяжёлого σ:

```
D_eff(exact) = [[ A - p²/C ,  x - p·y/C ],
                [ x - p·y/C,  B - y²/C  ]]
```

Опубликованный: `D_eff = [[A, x], [x, B − y²/C]]`.

Разность: `[[−p²/C, −p·y/C], [−p·y/C, 0]]` → **равенство только при p = 0**.

То есть опубликованная форма корректна **лишь при отсутствии прямого h–σ члена**.
Это неявное предположение нигде не оговорено.

### 2.B Противоречие с трёхлинейным порталом

Для одного портала `λ·h·I·σ` с фонами h→v+h, I→s+I, σ→w+σ:

```
x (h–I)     = λ·w      = λ·⟨σ⟩
y (I–σ)     = λ·v      = λ·⟨h⟩
p (h–σ)     = λ·s      = λ·⟨I⟩
```

Поскольку 2.A требует p = 0, получаем **λ·s = 0**. Следовательно:

* либо **s = ⟨I⟩ = 0** — тогда портал идёт через ⟨σ⟩ = w, и никакого «s ≠ 0» нет;
* либо published `D_eff` **неполон** и должен быть
  `[[A − p²/C, x − p·y/C], [x − p·y/C, B − y²/C]]`.

Условия «s = ⟨I⟩ ≠ 0 с трёхлинейным порталом» и «D_eff = [[A,x],[x,B − y²/C]]»
**взаимоисключающи**. Это внутреннее противоречие канона, которое нужно разрешить
до всяких численных прогонов.

### 2.C Диагонализация, тахионы, decoupling

* Собственные значения вещественны (симметричная матрица) — проверено, мнимая часть 0.
* Угол смешивания: **θ = ½·atan2(2x, A − B′)**, B′ = B − y²/C.
  Произвольный `sinθ` вместо диагонализации — **недопустим**.
  Benchmark (A=0.9, B=1.6, x=0.35, y=0.3, C=2.5): B′ = 1.564,
  собственные значения 0.7496 / 1.7144, θ = 66.744°, тахионов нет.
* Условие тахиона: `det D_eff = A·B′ − x² < 0`.
* Предел decoupling: C → ∞ ⇒ B′ → B, D_eff → [[A,x],[x,B]] — **PASS**.

### 2.D Ядро памяти: знак и полюса

Физический знаменатель даёт полюс `k₀² = k² + m²`. Знак «наоборот» даёт
`k₀² = k² − m²` — мнимые k₀ при k < m, то есть неустойчивость/призрак.
Знак ядра памяти **нужно выводить из вычета, а не постулировать**.

## 3. H3 — боттомоний (полный независимый расчёт)

### 3.0 Модель и её калибровка

Потенциал Корнелла `V(r) = −κ/r + σ·r + V₀`, κ = (4/3)α_s, m_b = 4.88 ГэВ.
Радиальное уравнение при l=0, конечные разности, трёхдиагональное `eigh`.

(α_s, σ) подогнаны по **двум независимым от V₀ расщеплениям** M(2S)−M(1S) и
M(3S)−M(1S); V₀ фиксирует абсолютную массу 1S. Результат:

```
α_s = 0.38625,  σ = 0.16883 ГэВ²,  κ = 0.515,  V₀ = −0.15312 ГэВ
расщепления: модель 0.56298 / 0.89478  против PDG 0.56296 / 0.89490  (откл. 3e-5 / -1.4e-4)
массы 1S/2S/3S совпали с PDG до 0.0001 ГэВ (по построению V₀)
```

Ограничение модели: Γ_ee выходит 2.14 / 0.785 / 0.556 кэВ против PDG 1.340 / 0.612 / 0.443 —
**завышение ~60%**. Это известная слабость нерелятивистского Корнелла с постоянным α_s.
Абсолютная нормировка |ψ(0)|² поэтому ненадёжна на ±50%, **отношения — надёжны**.

### 3.1 CONTACT-механизм: отношения **подтверждены данными**

Это сильный результат: контактные отношения PQT **верны**, и подтверждаются

Любая численная оценка при лёгком медиаторе, использующая этот предел, ошибочна.
