# Epistemic AI & Autonomous Governance (`epistemic-ai/`)

This directory contains the **Quantum Verification & Consensus Harness (QVCH)** v3/v4 framework, providing causal weight grafting, epistemic trace validation, and safety-gated execution monitoring.

---

## Architecture & Modules

* `qvch_v3/` & `qvch_v4/`: Core Python modules for epistemic boundary tracking, causal weight grafting, and consensus decision routing.
* `apps/`: CLI interfaces, API server endpoints, and harness runners.
* `scripts/`: Diagnostic and evaluation scripts.
* `tests/`: Automated unit and integration test suite (`pytest`).
* `BREAF/` & `docs/`: Technical specification briefs and implementation reports (`QVCH_v3_IMPLEMENTATION_REPORT.md`, `CHANGELOG_P0_V4_1.md`).
