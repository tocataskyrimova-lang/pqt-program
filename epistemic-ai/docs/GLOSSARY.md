# Glossary

- RawExperience: observed input before processing.
- NormalizedEvent: canonical event form.
- Noumenon / N: living unknown with lifecycle.
- U: hypothesis or transform track.
- F_candidate: fact candidate, not a crystal.
- Crystal: validated stable knowledge with non-LLM evidence.
- RepairPair: bad answer -> correction -> improved answer lineage.
- SkillCandidate: repeated successful repair pattern.
- WritePlan: complete pre-persistence decision object.
- MemoryWriteGateway: only legal persistence boundary.
