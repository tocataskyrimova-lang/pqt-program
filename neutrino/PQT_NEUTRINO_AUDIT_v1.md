## Главный вопрос: сколько параметров подобрано?

### Ответ: 9 подобрано, 4 наблюдаемых. Это переподгонка.

```
K_T содержит:
  k1, k2, k3           — 3 диагональных элемента        
  eps_12, eps_13, eps_23 — 3 внедиагональных амплитуды    -> ИТОГО: 9 свободных
  phi_12, phi_13, phi_23 — 3 фазы                        

Подогнано под:
  theta_12, theta_23, theta_13 — 3 угла PMNS             -> ИТОГО: 4 наблюдаемых
  Ratio Dm21^2/Dm31^2          — 1 отношение масс         
```

**9 параметров > 4 наблюдаемых = OVERFITTING.**

"Точность 10⁻²⁵" — это точность оптимизатора Nelder-Mead, **а не физическое предсказание**. С 9 свободными параметрами можно подогнать любые 4 числа с произвольной точностью. Это математическая тривиальность.

### Что это значит

| Заявление | Тип | Вердикт |
|---|---|---|
| θ₁₂ = 33.41° | FIT | **НЕ предсказание** — подобрано |
| θ₂₃ = 49.10° | FIT | **НЕ предсказание** — подобрано |
| θ₁₃ = 8.54° | FIT | **НЕ предсказание** — подобрано |
| Δm²₂₁/Δm²₃₁ = 0.0307 | FIT | **НЕ предсказание** — подобрано |
| "Точность 10⁻²⁵" | ARTIFACT | **Шум оптимизатора** |
| δ_CP = 0° | DEFAULT | **Артефакт эрмитова приближения** |

## Что является настоящим предсказанием?

Запущено 1000 случайных подгонок K_T. 855 сошлись (loss < 10⁻⁶). Все 855 проанализированы.

### ✅ Genuine #1: m_ν = 0 от Хиггса

Это **структурное** предсказание гексадного каркаса. S-мода (нейтрино) не связана с F-конденсатом. Юкавова масса тождественно нулевая. **Не зависит от K_T**.

### ✅ Genuine #2: Tamas-seesaw шкала

m_ν ~ Λ²_EW / m_ι. При m_ν ~ 0.05 эВ → m_ι ~ 10¹⁵ ГэВ. Это **структурное** предсказание шкалы Tamas-памяти. Совпадение с GUT/seesaw — не подгонка.

### ✅ Genuine #3: Нормальная иерархия

**100% из 855 решений дали нормальную иерархию (m₁ < m₂ < m₃).**

Это самый сильный результат. Независимо от конкретных значений 9 параметров K_T, структура эрмитовой матрицы с положительными диагональными элементами **всегда** даёт нормальную иерархию при подгонке под наблюдаемые отношения масс.

Проверяемо: JUNO (~2027), DUNE, Hyper-K.

### ⚠️ Weak #4: Сумма масс

| Метрика | Значение |
|---|---|
| min Σm_ν | 58.2 мэВ |
| max Σm_ν | 1892.7 мэВ |
| median | 73.4 мэВ |
| < 120 мэВ (Planck) | 77% решений |

Диапазон слишком широк для конкретного предсказания. Без фиксации масштаба Λ_T сумма масс не ограничена.

### ❌ Not a prediction #5: m₁ > 0

min(m₁) = 0.000 мэВ. PQT допускает безмассовое лёгкое нейтрино.

## Что нужно, чтобы превратить параметризацию в предсказание

### Опция A: K_T из первых принципов (0 свободных параметров)

Вывести каждый элемент K_T из кодонной алгебры Q-Mathematics. Если 64 кодона однозначно порождают 3×3 матрицу — это prediction мирового уровня.

**Статус**: НЕ СДЕЛАНО.

### Опция B: Симметрии снижают число параметров до ≤ 3

Если braiding + гексадная структура накладывают 6+ условий на 9 параметров:

```
Например:
  k1 : k2 : k3 = 21 : 21 : 22  (пропорционально числу кодонов)  -> -2 параметра
  eps_13 = eps_12 * eps_23       (транзитивность braiding)         -> -1 параметр
  phi_13 = phi_12 + phi_23       (аддитивность фаз)               -> -1 параметр
  
  Остаётся: 9 - 4 = 5 параметров. Всё ещё > 4 наблюдаемых.
  
  Нужно ещё 2 условия для genuine prediction.
```

**Статус**: НЕ СДЕЛАНО.

### Опция C: Структурные предсказания (текущий уровень)

Свойства, верные для **любого** K_T, согласованного с данными:

1. ✅ m_ν = 0 от Хиггса
2. ✅ Tamas-seesaw шкала ~ 10¹⁵ ГэВ
3. ✅ Нормальная иерархия (100% робастность)

Это и есть **реальный уровень предсказательной силы PQT neutrino v1**.
