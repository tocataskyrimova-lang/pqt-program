## СТРУКТУРНАЯ ТЕОРЕМА

### Rank генерационных проекций = 2 (не 3)

Из 16 eigenmodes графа K₄□K₄ только **3** имеют ненулевую проекцию на пространство поколений:

| Режим | λ | ΠV | Направление |
|---|---|---|---|
| V₀₃ | 4 | (+0.433, +1.299, −1.732) | ∝ (1, 3, −4) |
| V₃₀ | 4 | (−1.299, +1.299, +0.000) | ∝ (−1, 1, 0) |
| V₃₃ | 8 | (−0.750, +0.750, −0.000) | ∝ **(−1, 1, 0)** |

**V₃₃ коллинеарен V₃₀** в пространстве поколений: ΠV₃₃ = (1/√3) · ΠV₃₀.

**Все остальные 13 режимов проецируются в нуль.**

### Следствия

| Утверждение | Статус |
|---|---|
| Rank K_T^dyn в gen. space = **2** | **ДОКАЗАНО** |
| θ₁₂ = arccos(1/√3) = **54.74°** | **ФИКСИРОВАНО** (не зависит от κ, ε, β) |
| Никакое начальное условие не даёт rank > 2 | **ДОКАЗАНО** (все w₁, w₂ проецируются в 0) |
| Ratio ≈ 0.5 (два λ=4 режима доминируют) | **СТРУКТУРНОЕ** |

### Почему w₁, w₂ не работают

Базисные векторы w₁ = (1,−1,0,0)/√2 и w₂ = (1,1,−2,0)/√6 имеют:
- **Нулевую компоненту на δ** (w₁[3] = 0, w₂[3] = 0)
- **Нулевую сумму по {α,β,γ}** (Σ w₁[0:3] = 0, Σ w₂[0:3] = 0)

Поколения определяются по δ-позиции. Внутри каждого поколения α,β,γ суммируются → вклад w₁, w₂ обнуляется. Это **не зависит от начального условия**.

## Что НЕ работает и почему

### θ₁₂ = 54.74° (структурный предел)

Для θ₁₂ = 33.4° нужен **третий линейно независимый вектор** в генерационном пространстве. Но все eigenmodes с w₁ или w₂ проецируются в нуль.

**Возможные решения** (выход за рамки текущего формализма):
1. **Другой граф**: не K₄□K₄, а взвешенный граф с δ-чувствительными весами
2. **Другое разбиение**: не по δ-содержанию, а по Q-числу
3. **Нелинейная динамика**: взаимодействие мод → cross-coupling

### Ratio ≈ 0.5 (не 0.031)

Спектральная деформация m = λ^β не помогает:
- При β → 0: ratio → 1 (все массы сближаются)
- При β = 0.5: ratio = 0.51
- **Ratio не может быть < 0.5** при двух λ=4 режимах

Для ratio = 0.031 нужно **снять вырождение λ₁ = λ₂ = 4** → разные собственные значения.
