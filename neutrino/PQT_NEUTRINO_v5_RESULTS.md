## Почему centrality даёт отрицательные eigenvalues

### Braiding omega-таблица (вычисленная)

```
           alpha      beta     gamma     delta
alpha     1.0000   0.577+0.816j  1.0000  1.0000
beta   0.577-0.816j  1.0000   0.577-0.816j  1.0000
gamma     1.0000   0.577+0.816j  1.0000  1.0000
delta     1.0000   1.0000       1.0000  1.0000
```

**Проблема**: ω(α,γ) = 1 и ω(α,α) = 1, ω(γ,γ) = 1 → α и γ **неразличимы** для braiding-алгебры (оба в σ-слое +1). Это означает:

1. K_T[Gen1,Gen1] содержит слишком много единиц (кодоны αXα, αXγ все дают ω = 1)
2. Off-diagonal K_T[i,j] почти равен диагонали K_T[i,i]
3. Матрица почти вырождена → отрицательные eigenvalues после эрмитизации

### Корень проблемы: **σ-слойная структура слишком бедна**

Только 2 различных σ-слоя (+1, −1) на 4 глифа. α≡γ для braiding. Нужно:
- Либо различить α и γ (другой σ-assignment)
- Либо ввести дополнительную структуру сверх фазовых braiding'ов

## Итоговый вердикт серии v1–v5

> **PQT-нейтринная программа установила 5 структурных предсказаний (m_ν=0, 3 поколения, нормальная иерархия, Tamas-seesaw, Σm_ν), но не смогла вывести углы PMNS из кодонной алгебры. Корневая проблема — σ-слойная структура Q-Mathematics неразличима для глифов α и γ, что делает braiding-матрицу K_T вырожденной. Для количественного согласия необходимо либо обогатить σ-структуру, либо признать, что углы PMNS определяются динамикой сверх braiding-кинематики.**
