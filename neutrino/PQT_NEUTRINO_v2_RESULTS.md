- Либо braiding-тензор β порождает непрямое смешивание Gen1↔Gen3 через Gen2

## Что нужно для v3

### Проблема: ε₁₃ = 0 даёт θ₁₃ слишком малый

**Решение A**: Разрешить Хэмминг-2 переходы для ε₁₃ с подавляющим коэффициентом:
```
ε₁₃ = (adj_13_hamming2 / (N1*N3)) * suppression_factor
```
Число пар Gen1↔Gen3 с Хэмминг = 2: каждый из 9 кодонов Gen1 может перейти в αδδ через замену c₂→δ И c₃→δ. Это 9 пар. ε₁₃ = 9/(9·1) = 1.0 × suppression. Если suppression ~ 0.1, ε₁₃ ~ 0.1.

**Решение B**: Каскадное смешивание Gen1→Gen2→Gen3:
```
ε₁₃_effective = ε₁₂ × ε₂₃ × cascade_factor
```

**Решение C**: Пересмотр σ-слоёв — возможно, Gen3 (n_δ ≥ 2) включает не только αδδ, но и кодоны из расширенного алфавита.
